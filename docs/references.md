# Academic & Technical References

1. **QLoRA: Efficient Finetuning of Quantized LLMs**
   - Dettmers, T., Pagnoni, A., Holtzman, A., & Zettlemoyer, L. (2023). *QLoRA: Efficient Finetuning of Quantized LLMs*. arXiv preprint arXiv:2305.14314.
   - Introduced NormalFloat4 (NF4) data type, double quantization, and paged optimizers.

2. **LoRA: Low-Rank Adaptation of Large Language Models**
   - Hu, E. J., Shen, Y., Wallis, P., Allen-Zhu, Z., Li, Y., Wang, S., Wang, L., & Chen, W. (2021). *LoRA: Low-Rank Adaptation of Large Language Models*. arXiv preprint arXiv:2106.09685.

3. **Fast Inference from Transformers via Speculative Decoding**
   - Leviathan, Y., Kalman, M., & Matias, Y. (2023). *Fast Inference from Transformers via Speculative Decoding*. International Conference on Machine Learning (ICML).
   - Proved mathematically that speculative sampling produces generations identical to the target model distribution.

4. **Qwen 2.5 Technical Report**
   - Alibaba Cloud Qwen Team. (2024). *Qwen2.5: A Foundation Language Model Family*. GitHub Repository: https://github.com/QwenLM/Qwen2.5.

   - Canonical Ltd.: *Ubuntu Server Guide 22.04 LTS* (Ubuntu Documentation, 2024).
